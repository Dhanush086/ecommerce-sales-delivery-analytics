# Data

The raw data is not included in this repository.

Source: Olist Brazilian E-Commerce Public Dataset (Kaggle)
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Download the 9 CSV files and load them unchanged into a `staging` schema in
PostgreSQL (all columns as text). Then run `sql/01_clean_tables.sql`.
Check the dataset license on the Kaggle page before reusing the data.
